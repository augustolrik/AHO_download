# AHO_download

- Purpose: Public, download-only GitHub Pages library for student files.
- Open locally: run `node .site/scripts/generate-index.mjs`, then serve `.site-dist` with a local web server.
- Current state: Public repository is available at https://github.com/augustolrik/AHO_download and the download site is live at https://augustolrik.github.io/AHO_download/.
- Blockers: None.
- Next useful step: Add teaching files directly to this folder, commit, and push from GitHub Desktop; the download list updates automatically.
